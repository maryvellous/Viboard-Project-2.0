# Changelog

## 1.0.1

- chiudere la finestra mantiene Viboard attivo in background;
- aggiunta icona nella system tray di Windows con comandi Apri ed Esci completamente;
- avviare Viboard mentre è già in esecuzione riporta in primo piano l'istanza esistente;
- riapertura più rapida perché l'app non deve rifare il bootstrap completo.

## 1.0.0

Prima release stabile di Diaspro Viboard per Windows 10/11 x64.

### Novità principali

- esperienza desktop local-first senza server remoto;
- progetti, attività, pianificazione e documenti Markdown;
- dashboard e raccolta rapida;
- interfaccia Diaspro con branding Viboard;
- onboarding e interfaccia italiana rivisti;
- integrazione opzionale con Anthropic, OpenAI e DeepSeek;
- rimozione del sistema Riunioni dalla superficie utente;
- finestra Windows personalizzata senza chrome bianca;
- icona e installer Viboard dedicati;
- documentazione pubblica, policy di sicurezza e checklist di release.

### Note

- i dati restano nella cartella locale scelta dall'utente;
- l'auto-updater non è incluso nella 1.0.0;
- Linux resta sperimentale e non viene distribuito come build ufficiale;
- le build Windows possono essere non firmate e mostrare un avviso SmartScreen.
